# Legacy Dockerfiles (historical)

Dockerfiles by Hamza Sheikh (@aikchar), 2018, kept for reference. They build
the original Seagull sources with `build.ksh`, sctplib/socketapi and
OpenSSL 1.0.2e on CentOS 7, Ubuntu 16.04 and Ubuntu 18.04, and clone
`codeghar/Seagull` from GitHub, so they do not contain the changes of the
`modernizacion` branch. These base images are end-of-life.

For a current image use [`../almalinux-10`](../almalinux-10).
